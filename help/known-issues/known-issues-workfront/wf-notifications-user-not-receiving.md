# 通知：用户未收到预期的通知

当发生应向用户发送通知的事件时，该用户未收到通知。 即使用户通知设置允许通知，也可能发生这种情况。

此问题会影响应用程序内通知和电子邮件通知。

_首次报告于2026年2月12日。_
