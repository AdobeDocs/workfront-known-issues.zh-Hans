# 主页：主页因“内存不足”错误而崩溃

>[!NOTE]
>
>产品团队目前正在评估此问题的解决方案，这可能需要产品增强功能。 产品增强功能在“产品公告”中而非“维护更新”中传送。

当用户尝试查看新主页时，网站会崩溃并显示以下错误消息：

“显示此页面时出现错误！ 错误代码：内存不足”

**解决方法**

这可能是由于小组件中的项目太多造成的。 我们建议查看以下内容：

* 进行过滤，以便小组件中包含较少的项目
* 从主页移除小组件
