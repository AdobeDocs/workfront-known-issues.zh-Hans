# 校样：关闭校样后会重定向到文档列表

当用户查看校样并点击右上角的 X 图标关闭时，系统会将用户重定向到文档列表，而不是返回文档详情页。

当同时满足以下两个条件时，会出现此问题：

* 用户是通过链接打开校样的。 如果是从文档详情页打开校样，关闭校样时会返回文档详情页。
* 用户所在的组织尚未迁移到 Adobe Unified Shell。
