# 校样：无法从 PowerPoint 文件生成校样

当用户尝试从 PowerPoint 文件生成校样时，校样不会生成，并会显示错误消息。

**解决方法**

将 PowerPoint 文件导出为 PDF，然后从该 PDF 创建校样。
