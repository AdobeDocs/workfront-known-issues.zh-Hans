# 新 [!UICONTROL 主页]：小组件筛选条件和分组默认值不遵循版面模板

>[!NOTE]
>
>此问题已关闭，因为它已按预期运行。

当用户在新[!UICONTROL 主页]体验中查看[!UICONTROL 我的项目]、[!UICONTROL 我的任务]或[!UICONTROL 我的问题]小组件时，该小组件的默认筛选条件和分组不是分配给该用户的布局模板中的默认设置。

**解决方法**：

使用“新主页”时，请务必记住用户设置（偏好设置）的优先级。 因此，如果使用布局模板为特定小组件设置默认筛选条件或分组，由于现有的用户偏好，可能无法立即生效。 要应用新的筛选条件或分组，您或用户可能需要重置偏好设置。 这可以通过在 URL 中添加 `/resetUser` 来实现。
