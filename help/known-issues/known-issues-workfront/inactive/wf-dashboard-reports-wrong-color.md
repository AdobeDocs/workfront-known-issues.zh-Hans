# 仪表板：在仪表板中查看的报告图表使用与在报告中查看时不同的颜色

<!--Converted to story-->

>[!NOTE]
>
>产品团队目前正在评估此问题的解决方案，这可能需要产品增强功能。 产品增强功能在“产品公告”中而非“维护更新”中传送。

当用户在仪表板中查看报告图表时，使用的颜色与用户查看报告本身时不同。 如果用户预期给定的颜色具有给定的含义，则可能会导致混淆。
