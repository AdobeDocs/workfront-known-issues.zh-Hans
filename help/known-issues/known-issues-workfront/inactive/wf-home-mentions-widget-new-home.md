# [!UICONTROL 主页]：新 [!UICONTROL 主页] 中的 [!UICONTROL 提及] 小组件不限于其中标出了用户的消息

<!--Requested article, won't fix-->

>[!NOTE]
>
>此问题已关闭，因为它已按预期运行。

当用户在新[!UICONTROL 主页]体验中查看“[!UICONTROL 提及]”小组件时，看到了其中未标出或提及他们的评论。 该小组件包含评论，其中：

* 用户被分配获得任务或问题
* 用户对任务或问题进行了分配
* 用户创建了任务或问题
* 用户是任务或问题的主要联系人
