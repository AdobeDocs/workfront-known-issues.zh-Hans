# 请求：新请求体验中的草稿存在问题

>[!NOTE]
>
>此问题已于2026年2月9日修复。

关于新请求体验中的草稿，已报告以下问题：

* 以草稿创建并提交的请求，在“请求”列表中仅显示主题的首字母。
