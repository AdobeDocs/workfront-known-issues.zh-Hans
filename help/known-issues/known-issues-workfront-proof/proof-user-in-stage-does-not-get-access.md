# 校样：未与校样工作流中的用户共享校样

<!--This issue is on the WF and WFP TOCs-->
<!--Requested article, live for workaround-->

>[!NOTE]
>
>由于无法重现，此问题已关闭。

当校样到达用户在创建校样期间被添加到的工作流阶段时，不会与用户共享校样，并且用户无法访问校样。

**解决方法**

手动与用户共享文档。
