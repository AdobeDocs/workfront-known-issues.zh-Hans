# Workfront Fusion：Webhook 的更新不会自动保存

当用户对 webhook 进行更改（例如在 Workfront > 观看事件模块中）时，这些更改不会自动保存。

用户&#x200B;**必须保存场景**，才能保留对 webhook 的更改。

**解决方法**

保存该场景。
